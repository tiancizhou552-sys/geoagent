需要先配置合规底图的 Key

本项目不能使用 Leaflet + OpenStreetMap 直连瓦片——按国内地图合规要求， 允许的底图只有腾讯地图、高德、百度、天地图。

这里用的是腾讯地图 GL JS，需要你自己的免费 Key：

  1. 打开 https://lbs.qq.com/ → 控制台 → 应用管理 → 创建应用
  2. 添加 Key —— JavaScript API GL 不需要勾选任何产品，直接创建即可
  3. 在 Key 的「签名校验 / 域名白名单」里加上 127.0.0.1 和 localhost
  4. 把 Key 填进项目根目录 .env 的 TMAP_KEY=，重启本服务

Key 保存在服务端 .env 里（已被 .gitignore 排除），由模板注入页面。 注意：JavaScript API GL 的 key 必须出现在页面源码里——它要作为 &key= 参数传给 API 库，这是浏览器端地图 API 的固有特性。 真正的防护手段是在控制台里设置域名白名单，即使 key 被人抄走，别的域名也用不了。

对话功能不受影响，现在就能用——只是地图底图不显示。
